# 角色卡整理器（Bulk Tag Studio）

适配 SillyTavern 1.16.x 的第三方扩展。

## 从酒馆扩展页安装

在 SillyTavern 的“扩展”页面选择“安装扩展”，粘贴下面的仓库地址：

`https://github.com/zhishimocha/jiuguan-plugin`

安装完成后重启 SillyTavern，并在浏览器里强制刷新页面。角色页筛选图标栏的最右侧会出现一个分层图标。

## 功能

- 分类文件夹（默认首页）：现有标签自动成为一级分类；子分类横向滑动筛选并支持无限嵌套。角色卡按最近玩排序，点击即可打开该角色最近的聊天。
- 角色管理：采用统一的双列紧凑卡片，始终显示已有标签；排序与显示范围合并到一个入口，减少顶部占用。
- 高效筛选：可查看全部角色、完全无标签角色，或仅显示“未含所选标签”的角色；添加后保持当前位置继续整理。
- 标签录入：按“手动输入—选择已有标签—添加”三条通栏排列，已有标签默认选中使用最多的标签。
- 分类编辑：所有层级都可长按名称改名，右上角 × 删除，不再保留单独的名称编辑页。
- 角色移动：在分类页勾选角色卡后使用右上角“移动”，可移入子类、移到其他分类或移出当前分类；完成后自动清空勾选。
- 高级操作：位于角色管理页底部，清空全部标签前会自动下载 JSON 备份并再次确认。
- 界面风格：云雾蓝白、淡金描边的新中式视觉；角色头像保持原始色泽。
- 列表刷新：角色较少时不再强制撑出大片空白；删除角色后会等待酒馆数据更新并自动恢复列表。
- 更新体验：从 V2.2.0 起，在酒馆扩展管理中更新本插件或全部已启用插件后，检测到新版本会自动刷新一次页面。
- 界面字体：优先使用寒蝉活仿楷；字体以 SIL Open Font License 1.1 发布，加载失败时自动回退到系统楷体或默认字体。

## 手机本地覆盖安装

也可以把仓库中的四个文件复制到：

`~/st/public/scripts/extensions/third-party/bulk-tag-studio/`

如果原来已经安装 1.0 版，可以直接覆盖同名文件夹中的四个文件。插件的嵌套结构保存在酒馆设置中，原生标签本身仍由 SillyTavern 管理；即使停用插件，角色卡上的标签也不会消失。

## 删除说明

删除角色卡不可撤回。默认只删除角色卡并保留聊天；勾选“同时删除聊天记录”后，相关聊天也会一并删除。文件夹删除不会删除任何角色卡。
